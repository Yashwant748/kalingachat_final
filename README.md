# KalingaAI – Local AI Assistant for Academic Use

## 1. Overview
KalingaAI is a local AI assistant designed for academic environments.  
It runs fully offline using local language models and provides tools for students and faculty.

## 2. Features
- Local AI Chat System
- Offline AI using Ollama
- Fast and Smart Model Switching
- APA and IEEE Citation Generator
- Attendance ERP Excel Generator
- Multilingual Support
- Dark/Light Mode
- System Status Indicator

## 3. Technology Stack
**Frontend:**
React + TypeScript + Tailwind

**Backend:**
Node.js + Express

**AI:**
Ollama Local Models

## 4. Run Instructions
```bash
npm install
npm run dev
```

Open:
http://localhost:5173
